## BAGIAN II: KETENTUAN LAYANAN & PENGGUNAAN (TERMS OF SERVICE)

### Pasal 4: Kepatuhan Terhadap Platform Pihak Ketiga
1. Noisy Virus beroperasi dengan berinteraksi pada layanan dan Application Programming Interface (API) pihak ketiga (VirusTotal yang dioperasikan oleh Google LLC, Google Fonts, serta YouTube untuk pemutar semat).
2. Pengguna memahami sepenuhnya bahwa setiap platform memiliki Ketentuan Layanan serta kebijakan Public API masing-masing, termasuk batas kuota dan aturan penggunaan data hasil pemindaian.
3. Segala akibat dari penggunaan Noisy Virus — termasuk namun tidak terbatas pada pembatasan akses oleh platform, pemblokiran kunci API, atau pelanggaran ketentuan platform — adalah **tanggung jawab penuh Pengguna**. cokguss tidak bertanggung jawab atas kerugian tersebut.
4. Pengguna wajib menggunakan layanan hanya untuk memeriksa file dan tautan miliknya sendiri atau yang berhak diperiksa, dan dilarang memakainya untuk aktivitas ilegal.

### Pasal 5: Ketersediaan Layanan & API Pihak Ketiga
1. Noisy Virus disediakan secara **gratis** tanpa skema berlangganan apa pun.
2. Noisy Virus bergantung pada API pihak ketiga yang dapat berubah, membatasi, atau berhenti sewaktu-waktu di luar kendali cokguss. Kegagalan fungsi pemindaian akibat perubahan pihak ketiga bukan merupakan cacat produk maupun kewajiban ganti rugi.
3. Mode stealth bergantung pada struktur antarmuka VirusTotal yang dapat berubah sewaktu-waktu; pengguna dianjurkan menyertakan kunci API resmi untuk kestabilan jangka panjang.

### Pasal 6: Privasi Data
1. Noisy Virus tidak meminta registrasi akun dan tidak mengumpulkan data pribadi Pengguna.
2. Hash file, file yang belum dikenal, dan URL yang diperiksa diteruskan ke VirusTotal sesuai alur pemindaian; laporan hasil pemindaian hanya disimpan sementara di memori server selama maksimal 10 menit sebagai cache, lalu hilang.
3. Penyematan pemutar YouTube (fitur suara) serta pemuatan Google Fonts dapat menyetel cookie atau penyimpanan lokal sesuai kebijakan masing-masing penyedia.
