Ringkasan singkat

Noisy Virus adalah alat pemindai tanpa akun. Kami tidak menyimpan database pengguna, tidak memasang pelacak, dan tidak menjual data apa pun. Sebagian besar pemindaian bahkan tidak pernah mengirim file Anda ke mana pun — cukup sidik jarinya.

Data yang diproses saat pemindaian

  • File yang Anda unggah dihitung hash SHA-256-nya secara lokal di browser. Jika hash sudah dikenal VirusTotal, file tidak pernah dikirim — hanya hash 64 karakternya.
  • File baru yang belum pernah dilaporkan akan diunggah sekali ke VirusTotal untuk dipindai oleh puluhan mesin antivirus.
  • Tautan (URL) yang Anda masukkan diteruskan ke VirusTotal untuk diperiksa reputasinya.
  • Laporan hasil pemindaian disimpan sementara di memori server selama maksimal 10 menit sebagai cache, lalu hilang.

Layanan pihak ketiga

  • VirusTotal (dioperasikan oleh Google LLC) menerima hash, file, atau URL yang Anda pindai. Privasi terkait data tersebut diatur oleh kebijakan privasi VirusTotal.
  • YouTube memuat pemutar video semat hanya saat Anda mengaktifkan fitur suara. YouTube dapat mencatat interaksi tersebut sesuai kebijakannya sendiri.
  • Font dari Google Fonts dimuat untuk keperluan tampilan.

Penyimpanan lokal di perangkat Anda

Situs ini menyimpan satu preferensi di localStorage perangkat Anda: pilihan bahasa (ID/EN). Tidak ada cookie iklan, cookie analitik, atau fingerprinting.

Yang tidak kami lakukan

  • Tidak ada pendaftaran akun — kami bahkan tidak punya tempat menyimpan identitas Anda.
  • Tidak ada analitik atau pelacakan perilaku.
  • Tidak ada penjualan atau pembagian data kepada pemasar.
